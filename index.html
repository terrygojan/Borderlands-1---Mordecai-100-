Configuración del proyecto

1 Coloca tu JSON principal en data/board.json. La página lo cargará automáticamente.
2 Coloca tus imágenes propias en images/ usando el nombre de la carta. Las imágenes locales tienen prioridad.
3 El progreso de las cartas se guarda en este navegador y no modifica el JSON.
Si data/board.json no se puede cargar, esta pantalla queda disponible para importar el JSON manualmente.
